# 快速开始

RemoteCI 由**服务端与 WebUI**、**ClassIsland 插件**和**可选客户端**组成。服务端保存账号、权限、班级档案、课表与运行记录；WebUI 是主要管理入口；插件运行在教室电脑上，连接 ClassIsland；手机网页、Android 与 Wear OS 按需使用。只在同一局域网内使用手机或手表直连插件时可以不部署服务端，但账号、档案、集控与教务功能都依赖服务端。

## 准备工作

| 组件 | 要求 |
| --- | --- |
| 服务端 | Docker、Windows 或 Linux；建议有域名和 HTTPS。发布包提供 linux-x64 / linux-arm64 / win-x64 |
| 教室电脑 | ClassIsland 2.1.0 及以上；RemoteCI 插件 3.3.2.1（以最新 Release 为准） |
| 浏览器 | 任意现代浏览器；手机网页 / PWA 无需安装 |
| Android 手机 | Android 8.0（API 26）及以上 |
| Wear OS 手表 | Wear OS 3（API 30）及以上 |
| 网络 | 服务端默认 TCP 8080；插件局域网直连默认 TCP 8765，设备发现使用 UDP 48765 |

从 [GitHub Releases](https://github.com/Edge-HH/RemoteCI/releases/latest) 获取发布包：服务端压缩包（linux-x64 / linux-arm64 / win-x64）、插件 `RemoteCI.Plugin.cipx`、手机 `RemoteCI.Mobile-<版本>.apk`、手表 `RemoteCI.Watch-<版本>.apk`、飞牛 fnOS 在线与离线 FPK，以及 `ghcr.io/edge-hh/remoteci` 多架构镜像。

## 一、部署服务端

按照[服务端部署](../server/deployment.md)使用仓库自带的 <code>compose.yaml</code>、发布包或飞牛 fnOS 完成部署。服务端不再生成随机初始密码，也不再自动创建“默认班级”。首次在浏览器打开 WebUI 时会进入**初始化向导**：

1. **创建系统管理员**：填写登录 ID（默认 `admin`）、显示名称和密码。系统管理员拥有全部权限，并且只能由本人修改，其他管理员不能编辑、停用、重置密码或删除它。
2. **新建第一个班级**：填写班级名称。之后可以在“管理 › 班级”中继续添加班级。

完成后进入概览页。新建账号不会自动加入任何班级：在“人员与角色”新建学生或班主任时选择所属班级；老师按课表中的教师姓名自动绑定任教班级。

## 二、连接 ClassIsland 插件

1. 在 ClassIsland 中安装 RemoteCI 插件（插件市场或 `RemoteCI.Plugin.cipx`）。
2. 打开“设置”中的“RemoteCI 设置”。
3. 普通设置中确认局域网端口（默认 <code>8765</code>）；局域网服务默认开启。若需连接开关或语音接收测试，开启“显示开发者设置菜单”并重启 ClassIsland。
4. 填写云端服务端的完整地址；普通设置不提供关闭云端中转的开关。
5. 登录服务端 WebUI，确认右上角选中的是要连接的班级，在概览页点击“生成插件配对码”，把显示的配对码填入插件设置。配对码 30 分钟内有效，成功配对后立即作废。
6. 保存设置并重启 ClassIsland。
7. 回到“RemoteCI 设置”，确认“服务器状态”为已连接；若仍在等待配对或重试，查看最近错误并点击“测试服务器连接”。

插件换到长期凭据后会清空本地配对码，之后会自动接收账号、权限与设备验证器镜像。

::: tip 地址写法
本机测试可以填写 <code>http://localhost:8080</code>。手机、手表或公网访问时，应填写可被设备访问的地址；生产环境使用 HTTPS，例如 <code>https://remoteci.example.com</code>。
:::

## 三、建立账号与权限

登录 WebUI 的“管理 › 人员与角色”，为使用系统的人员创建账号：

- **ID 与用户名**：ID 是登录唯一标识，3-32 位字母、数字、点、下划线或短横线；用户名是显示名，会出现在通知和老师绑定中。两者都可以用来登录，因此共用一个命名空间，不能与其他账号的 ID 或用户名重复（不区分大小写）。
- **初始密码**：8-128 位，也可以留空；留空时账号处于“待设置密码”状态，使用者首次登录时自行设置。密码只用于登录，不会下发到插件或写入客户端。
- **角色**：内置系统管理员、班主任、老师、学生，也可以创建自定义角色。学生和班主任需要选择归属班级；老师不选班级，按用户名与课表中的教师名自动关联任教班级，因此老师用户名应填写课表里使用的教师姓名。
- **权限**：选择角色后，清单按该角色的默认权限自动勾选；勾选或取消即为个人新增 / 收回。权限分为班级内与全局两组，详见[账号与权限](features.md#账号与权限)。
- **安全**：建议开启 [TOTP 二步验证](../server/operations.md#安全清单)，并只授予实际需要的权限。系统管理员还可以在“个人 → API Key”中为自动化创建密钥。

需要创建多个账号时，可在同一页面下载 Excel 模板批量导入；班主任和学生必须指定班级。需要批量维护班级分组与成员时，可在“管理 › 班级”使用 Excel 导入导出。

## 四、配置班级档案与基础设置

1. **班级档案**：进入“班级管理 › 本班档案”，从教室电脑收集、上传现有 ClassIsland 档案或新建。插件从未同步过课表时，WebUI 会按这份档案推算七天课表；插件上线后以插件课表为准。
2. **科目教师与地点**：在“课表”页为科目填写任课教师和上课地点。教师名用于老师绑定与“我的日程”，地点显示在课表、我的日程和系统日历中。
3. **学期与调休**：在“管理 › 学期与调休”设置学期开始日期，让单双周和多周轮换在各端一致；服务端会自动获取法定节假日与调休安排，也可以手动指定补课日。
4. **班级策略**：在“管理 › 班级”的班级菜单中按需限制教室端编辑档案、修改设置、打开插件页或退出集控；策略会下发到该班全部在线设备。
5. **插件与守护**：在“管理 › 插件控制”中按班级下发扩展插件设置；在“管理 › 应用守护”中统一配置退出自启、崩溃重启与禁止删除。

## 五、使用 WebUI

WebUI 左侧导航按任务分为“概览、课表、班级管理”“我的日程、换课”“管理、记录与统计、系统设置、个人”：

- **概览**：当前课程、插件连接、课表同步与能力诊断。
- **课表**：查看多彩周表格、直接换课、设置科目教师与地点、申请换课。
- **班级管理**：当前班级的控制、本班档案、插件设置与电子班牌。
- **我的日程 / 换课**：老师聚合跨班课次、管理自定义课程、处理换课申请。
- **管理**：设备状态、批量控制、自动化、应用守护、插件控制、班级、人员与角色、档案库、学期与调休。
- **记录与统计**：操作记录与课时统计。
- **系统设置**：常规、维护、登录与访问、插件与课表同步。

完整功能见[功能说明](features.md)。

## 六、连接手机与手表

- **手机浏览器 / PWA**：用手机打开同一服务器地址，登录后自动进入手机界面；iPhone / iPad 可从 Safari“添加到主屏幕”并开启通知与系统日历订阅。
- **Android**：安装 `RemoteCI.Mobile-<版本>.apk`，输入服务器地址、ID 和密码，或在登录页扫描 WebUI 生成的“手机扫码登录”二维码；支持桌面小组件、上课状态通知与系统日历同步。
- **Wear OS**：安装 `RemoteCI.Watch-<版本>.apk`，填写服务器地址与个人账号登录；可优先局域网连接教室端插件，失败时回退到云端中转。

手机与手表都使用个人账号，不需要插件配对码。二维码 5 分钟内有效且只能使用一次；二维码里的服务器地址必须能被手机实际访问，电脑上的 `localhost` 对手机无效。WebUI 经反向代理或内外网地址不同时，拥有“登录页与访客”系统权限的账号可在“系统设置 → 登录与访问 → 手机扫码登录”中指定二维码使用的服务器地址。

## 七、确认连接

- 服务端概览显示插件在线；Android 手机会显示为独立的移动端连接。
- ClassIsland 的“RemoteCI 设置”显示服务器已连接，主动连接测试成功。
- WebUI 能查看当前课程与课表，手机或手表能收到状态更新。
- 有权限的账号可以提交一次非破坏性操作（例如发送通知）并看到真实回执。

如果其中一步失败，请查看[连接方式](connection.md)和[故障排查](troubleshooting.md)。
