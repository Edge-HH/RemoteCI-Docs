# 功能说明

## WebUI 工作区

WebUI 采用桌面仪表盘式布局：左侧导航按账号权限显示可用页面；老师和班主任账号会在课表和控制入口下方看到“我的日程”，按姓名只列出自己任教班级的课次；顶部搜索框可按名称快速跳转到页面或常用任务。概览页集中展示当前课程、插件连接、在线手表、账号数量、课表同步与插件凭据；侧栏可在桌面端收起，并在窄屏上改为抽屉导航。

顶部提供当前页面刷新、明暗主题切换和个人账号入口；个人账号页可修改密码、撤销设备会话，系统管理员还可在此修改自己的用户名；其他账号的用户名由管理员在“人员权限”中维护。WebUI 默认采用深石墨色界面，可在顶部切换浅色主题；主题与桌面侧栏收起状态保存在当前浏览器中，不会修改服务端账号或其他设备的设置。

访问不存在的 WebUI 地址时，服务端会显示 RemoteCI 自己的“页面不存在”状态页，而不是浏览器默认错误页；页面上的按钮会按当前登录状态返回登录页、概览或个人账号。`/api/*` 与 `/ws` 的错误响应保持原样，便于脚本和客户端按状态码处理。

## 课程状态

插件从 ClassIsland 收集当前课表状态，每秒推送给手表和服务端：

- 当前课程与下一节课程。
- 当前时间段和下一时间段。
- 上课或课间剩余倒计时。
- 课表方案名称、是否启用和是否已加载。
- 状态生成时间，用于判断数据是否过期。
- 主界面显隐状态、睡眠/休眠可用性，以及音量状态（是否可控、百分比、静音）。

当前时间段使用插件本地时间，并随快照携带插件时区偏移（`timeZoneOffsetMinutes`）。手表以快照的 UTC 生成时间加该偏移推算插件本地当前时间，再计算课程进度环，因此即使手表与电脑时区设置不一致，上课/课间进度环也能正常显示。

## 七日课表

服务端保存插件最近一次推送的七日课表，包含每天日期、修订号、课程列表和科目清单。所有已登录账号都能在 WebUI、手机和手表查看七日课表；从插件拉取课表只对系统管理员和获准的本班班主任开放（见[班主任权限](#班主任权限)），自动拉取周期是对全部班级生效的全局设置，只有系统管理员可以修改；换课仍需要“换课”权限。插件离线后仍可查看最后一次同步的数据，但更新时间可能已经过期。

插件每次连接云端时，服务端都会自动拉取一次最新课表。ClassIsland 的“RemoteCI 设置”提供“立即推送当前课表”，可主动把当前七日课表发送给服务端和在线手表，并显示成功、失败或超时。系统管理员和获准的本班班主任可在 WebUI 侧边栏“课表”页面点击“立即拉取课表”，成功后用插件最新课表覆盖服务端缓存；手表与手机课表页也只对这两类账号显示拉取入口，其他账号看不到该按钮，发出的拉取请求会被服务端忽略。插件推送、WebUI 拉取、手表拉取、自动拉取和连接初始化共享一个课表任务锁；系统管理员还可把在线期间的自动拉取周期设置为关闭、每 15 分钟、每小时、每 6 小时或每天。插件离线时请求不会排队，重新连接后会自动再拉取。

WebUI 换课表单中的原节次与目标节次都以“日期 · 节次 · 科目”列出；服务端会按当前缓存课表验证所选日期、修订号和节次，交换目标必须是原节次同一天的其他课程。

换课时可勾选“永久换课”。默认操作只修改当天临时课表；永久换课会把交换或替换写入 ClassIsland 源课表，使本周及以后每周继续生效。Android 手机、Wear OS 手表和 WebUI 使用同一字段，插件会按请求选择对应课表层。手机端的能力快照仅用于提示，换课最终仍由服务端按当前班级权限和插件能力复核；快照短暂缺失时不会直接吞掉提交，服务端会返回具体失败原因。

访客页只展示已开放访客功能的班级课表；班级较多时可按班级分组筛选，选择父分组会同时包含其子分组中的班级。访客只能切换班级并只读查看课表，不能进入管理功能。

## 调休自动适配

服务端自动获取法定节假日与调休安排：放假日教室课表自动关闭，原本是周末但要上学的日子自动开启一份补对应工作日课程的临时课表。系统管理员可在 WebUI「调休」页调整每个调休上学日补哪天的课，或关闭此功能。详见[调休](./holidays.md)。

## 老师、班主任角色与我的日程

服务端内置“老师”角色，默认权限为查看当前课程、发送与清除通知、发送语音和 API 访问，可在“人员权限 → 角色配置”中追加。老师账号不需要加入班级：服务端把账号的用户名（显示名）当作老师姓名，与各班课表里科目的教师名比对，姓名一致的班级就是该老师的任教班级，老师在这些班级内拥有老师角色的权限。

- 匹配规则：去掉首尾空白后完全相等；教师名写成 `张三/李四` 这类多人列表时（支持 `、 , ， / ; ； |` 分隔），填写其中任一姓名即可。同名老师会绑定到同名课程，建议使用完整姓名。
- 科目教师：拥有“换课”权限的账号可在 WebUI 课表页的“科目教师”区为当前班级的每个科目填写授课教师名，留空表示清除；保存后写入教室端 ClassIsland 档案并立即重新同步课表。教室端插件版本过旧时该区域会提示升级插件。
- 我的日程：老师登录 WebUI 后，侧边栏出现“我的日程”，按日期列出自己在各任教班级的课次、节次和时间；手机端课表页默认显示“我的日程”，可切换回“本班课表”。
- 班主任：内置“班主任”角色（原“班管理员”）保留本班管理能力，同时和老师一样按用户名获得“我的日程”与下一节课接口；按姓名获得任教班级访问权仍只适用于老师角色。内置角色名固定，不能在角色配置里改名，用户名也只能由系统管理员修改。
- 生效时机：绑定根据服务端缓存的课表实时计算，不写入数据库。服务端刚重启、教室端插件尚未推送课表时，任教班级和“我的日程”暂时为空，收到课表后自动恢复。

- API 与 Agent：老师和班主任可在“个人账号 → API Key”创建密钥，通过 `GET /api/me/schedule` 和 `GET /api/me/schedule/next` 读取自己的日程和下一节课。RemoteCI 仓库附带的 `remoteci` Skill 让 AI 助手以你的账号工作，用 API Key 或账号密码登录。它面向所有角色：学生查课表；老师问“下节课去哪个班上什么”；班主任控制本班；系统管理员创建和管理班级、分组、人员与成员分配。详见[API 接口](../server/api.md#在-ai-agent-中使用-remoteci)。

因为用户名决定老师能看到哪些班级和课次，用户名只允许系统管理员修改。

## 老师换课申请

老师不需要“换课”权限，也可以自己找其他老师换课：在 WebUI 侧栏“个人 → 换课”或 Android 手机底栏“换课”页发起申请，对方老师同意后立即写入教室端课表。申请都是临时换课，只影响所选日期；永久换课仍由班主任在课表页操作。

- **互换两节课**：分别选择“要换走的课”和“目标课”（班级 → 日期 → 节次）。两节课可以在不同班级、不同日期，也可以选别人的课，但至少有一节必须是自己的课。跨班互换时，学科按名称在两个班里对应；某个班没有对应的学科时无法提交。
- **替换为我的课**：只选目标课，再选择一门自己任教的学科，目标课就会临时改成你上的这门课。目标班可以不是你教的班；这节课会记在你名下，进入你的“我的日程”。
- **理由**：必须填写，对方审批时可以看到。
- **审批**：申请发给对方课的老师。课表里那位老师没有 RemoteCI 账号时，改由该班班主任审批。对方会在 WebUI 铃铛、浏览器通知、手机通知和已绑定的 AstrBot 会话里收到提醒，可以查看理由后通过或拒绝（可附备注）。通过后立刻通知申请人和相关班主任；拒绝也会立刻通知申请人。待审批期间申请人可以撤销。
- **生效**：通过时服务端会按最新课表重新核对两节课。课表已被别人改过时，会提示“已被调整，请重新申请”；教室端离线时，申请保持待审批，可以稍后再点通过。
- **临时任课老师**：换课后，某节课实际上课的老师可能与该科目在班里的默认老师不同，例如替换为你的数学课，但这个班的数学平时由别人教。RemoteCI 会为这一节记录临时任课老师，手机、手表、WebUI 课表和个人日程都按实际上课的老师显示。教室大屏上的 ClassIsland 仍显示科目的默认老师。

### 强制换课

系统管理员在“人员权限 → 角色配置”中可以为角色开启“强制换课”（默认关闭）。开启后，换课页会多出红色的“强制换课”按钮，点击后先弹窗提示“仅在需要紧急换课时使用，请提前与对方沟通并达成一致。”，确认后不经审批直接换课，并通知对方老师“你的课已被强制换走”。

对方老师可以在“待我处理”中撤回。撤回后课表恢复原状，并通知申请人。同一位老师当天不能再强制换走这节课，只能提交普通申请；这不影响其他课、其他老师，也不影响下一周的同一节课。

### 权限开关

“老师主动换课”和“强制换课”都在“人员权限 → 角色配置”中按角色开关，也可以在编辑账号时单独追加。内置老师和班主任默认开启“老师主动换课”、关闭“强制换课”。关闭“老师主动换课”后，侧栏和手机底栏的“换课”入口会隐藏。

### 浏览器通知

WebUI 顶栏的铃铛显示未读通知数，点击进入“通知”页；在这里点“开启浏览器通知”并允许通知后，即使关闭网页，也会在系统通知中心收到换课提醒。浏览器通知要求 WebUI 通过 HTTPS（或本机 localhost）访问；普通 HTTP 局域网地址只能在打开网页时通过铃铛看到提醒。Chrome 的推送依赖 Google 推送服务，部分网络可能收不到，可改用 Edge 或 Firefox。

## 账号与权限

服务端使用独立账号登录，有效权限是位掩码：

| 值 | 权限 |
| --- | --- |
| 1 | 查看当前课程（普通用户固定拥有） |
| 2 | 概览 |
| 4 | 人员管理 |
| 8 | 发送与清除通知 |
| 16 | 换课 |
| 32 | 电源控制（含音量） |
| 64 | 保留权限位（暂时隐藏） |
| 128 | 扩展功能 |
| 256 | 主界面 |
| 512 | 发送语音 |
| 2048 | API 访问 |
| 4096 | 老师主动换课（发起与审批换课申请） |
| 8192 | 强制换课 |

管理员的有效权限固定为 16383（全部权限）。普通用户默认只含值 1，但无论是否拥有概览或换课权限，都可以进入 WebUI 课表页查看课表。其余权限由管理员在“人员权限”页面分配。设备会话可以被撤销；个人账号修改密码和人员管理重置密码都必须重复输入相同的新密码，修改成功后原有设备登录会失效。

在“人员权限”页新建账号时先选择角色：选择学生、班主任等非管理员角色必须同时指定归属班级，账号创建后会加入该班级；管理员账号不参与班级成员关系，无需分配班级；老师账号按用户名自动关联任教班级，创建时同样不选择班级。

## 成员 Excel 导入导出

管理员可在“人员权限”页批量维护班级成员。下载模板后按“用户 ID、用户名、班级、角色、密码”填写并上传：普通导入只创建新账号，密码可留空表示首次登录时设置；已存在的用户 ID、非法字段和文件内重复项会逐行列出，其他合法行仍会导入。

导出文件按“全部班级”或指定班级分组生成，包含“用户 ID、用户名、班级、角色”和用于识别账号的隐藏系统标识，不包含密码。可修改用户名、班级和班级角色后，使用“覆盖导入”上传同一文件；服务端只更新文件中出现的成员关系，文件中缺失的关系会保留，不会修改已有账号密码。覆盖导入会先完整校验，存在错误时不会写入任何变更。
## 系统配置

管理员侧边栏提供“系统配置”页面，包含系统更新、通知人显示、手机扫码登录、自动备份和加密配置的导入导出。“手机扫码登录”可指定概览页登录二维码中写入的服务器地址（例如反向代理后的公网地址），留空则使用当前 WebUI 访问地址；该设置只影响二维码内容，不改变服务端监听地址，并随配置备份一起导出。“通知人显示”决定自定义通知标题是否附带发送人，对所有班级生效，只有系统管理员可以修改。个人账号页面用于管理密码、设备会话与 API Key；修改用户名仅系统管理员可用。

## 登录页设置

管理员侧边栏提供独立的“登录页设置”页面，用于自定义未登录访问时登录页的外观：

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 主题 | 跟随访客偏好 | 可选浅色模式或深色模式；强制后登录页不再受浏览器本地明暗偏好影响 |
| 背景图 | 无（默认网格背景） | PNG/JPEG/WebP，不超过 2MB，铺满整屏；留空上传表示保持现有背景 |
| 背景不透明度 | 100% | 0-100%，按百分比淡化背景图，便于与登录卡片保持对比 |
| 登录卡片位置 | 居中 | 左、中、右三档，决定登录框在页面中的水平位置；窄屏下登录框仍会自动收缩到可用宽度 |

背景图保存在服务端数据库中，随数据库一起备份与迁移；设置页提供实时预览，保存后才生效；预览下方提供“移除背景图”恢复默认网格背景。访客页与登录后的界面仍沿用浏览器本地主题，不受此设置影响。

配置包只迁移主题、背景不透明度与登录卡片位置三项标量设置，背景图不在其中；换机器部署后需要重新上传背景图。

## WebUI 控制

WebUI 侧边栏提供“控制”入口。发送通知、清除通知、主界面、音量、电源和扩展功能都集中在控制页面，并同时按账号权限与“服务端 ∩ 当前主插件”能力显示。

进入“控制”页后，可以查看插件上报的主菜单、音量、静音和电源能力状态，并执行与手表控制页相同的操作。插件离线时按钮不可用；电源操作在提交前要求再次确认。

控制页的“扩展功能”区按插件分组显示：同一个 ClassIsland 插件注册的功能排在一起，分组标题下显示插件说明，未声明分组的功能归入“其他扩展”。带参数的功能会弹出参数表单，表单按插件声明显示字段名称、说明、占位提示、数字范围和选项显示名称，提交前由服务端按同一规则校验。插件声明了设置页时，分组右侧出现“插件设置”按钮（系统管理员始终可见，班主任需要在[班主任权限](#班主任权限)中获准）。

### 扩展插件设置页

“扩展插件”页（系统管理员在侧边栏“管理”下进入，班主任从控制页的“插件设置”进入）汇总设备上报了设置页的插件：

- **当前班级**：表单按本班设备上报的当前值预填，保存后由插件在本班设备上写入并生效。
- **批量下发**（仅系统管理员）：勾选要修改的设置项并填写新值，选择班级或分组后下发；未勾选的设置项保持各班原值。所选班级中的每一台在线设备都会收到，结果逐台显示。
- **各班级当前值**（仅系统管理员）：表格列出每个班级上报的设置值，与多数班级不一致的单元格会高亮，便于发现个别班级被改动。

设置值以设备上报为准。下发时班级插件离线（或单班保存时插件不在线）的设置会被服务端记为“待补发”，结果中显示“已保存，插件上线后自动补发”；插件重新连接并同步扩展分组后自动写入，“各班级当前值”表格的“待补发”列会显示尚未生效的新值。补发时会再次确认下发者仍有修改权限，插件给出明确结果后不再重复补发。

## 班级管理

管理员可在“班级管理”中按学校、年级或校区维护多层分组树。选择左侧分组后，右侧会列出该分组及全部子分组中的班级；勾选多个班级后，可以批量开启或关闭访客、加入或移出分组、设置为所选分组、清空分组，或删除班级。分组树顶部的“未分组”节点会列出尚未归入任何分组的班级，便于批量加入分组。分组的新建、改名、移动和删除都收在树节点菜单中，班级仍可同时属于多个分组。

### 班主任权限

“班级管理”页的“班主任权限”面板统一决定班主任能否在自己的班级里自行完成以下操作，对全部班级生效，系统管理员始终不受限制：

| 选项 | 默认 | 影响 |
| --- | --- | --- |
| 修改本班班名 | 开启 | 控制页“班级设置”中的班名表单与 `PUT /api/classes/{id}/info` |
| 上传或清除本班头像 | 开启 | 控制页“班级设置”中的头像表单与班级头像 API |
| 手动从插件拉取本班课表 | 开启 | 课表页、手表与手机的“拉取课表” |
| 修改本班的扩展插件设置 | 关闭 | 控制页“插件设置”入口、扩展插件设置页与扩展设置 API；班主任还需在本班拥有“扩展功能”权限 |

关闭某一项后，对应入口会从班主任的界面中隐藏，直接调用接口会返回 403。脚本和 Agent 可通过 `GET` / `PUT /api/settings/class-self-service` 读取或修改同一组开关（修改仅限系统管理员）。课表定时拉取间隔是全局设置，不受此面板控制，只有系统管理员可以修改。

## 班级 Excel 导入导出

管理员可在“班级管理”页用 Excel 批量维护班级与分组，流程与“人员权限”页的成员导入导出一致。

模板包含一个 `.xlsx` 文件中的两个工作表：

| 工作表 | 列 | 说明 |
| --- | --- | --- |
| 分组 | 分组名称、上级分组 | “上级分组”留空表示根分组，填写父分组名称即可建立层级；最多 4 层 |
| 班级 | 班级名称、分组、访客访问 | “分组”填班级所属分组名称，多个分组用分号 `;` 分隔；“访客访问”填“是”或“否” |

- **导入新建**：填写模板后上传，只创建新的班级与分组。名称已存在、上级分组缺失、层级超限或字段非法的行会逐条列出失败原因，其他合法行仍会创建。
- **导出并覆盖修改**：按“全部班级”或指定班级分组导出，导出文件带隐藏的“系统标识”列和“导出信息”工作表。可修改分组的“分组名称/上级分组”、班级的“班级名称/分组/访客访问”，新增行会创建新对象。

覆盖导入采用保守策略：**只新增与修改，不会删除**。删除文件中的某一行不会删除对应班级或分组；需要删除时仍应使用班级管理页的批量删除或分组节点菜单。覆盖导入会先完整校验，发现任一错误时不写入任何变更。

## 批量控制

管理员侧边栏的“批量控制”页面采用“功能卡片 → 参数弹窗 → 目标设备弹窗”的两步流程。先选择通知广播、清除通知、电源、语音、修改时间表、分发档案、插件管理、软件更新、加入集控、插件管理策略、远程终端或文件分发，再填写该功能的参数，最后选择班级、分组或具体设备。按班级或分组选择时，每个班只发送到最早接入的在线设备；按具体设备选择时逐台发送。

批量控制按插件长期凭据列出所有已配对设备，并显示在线状态、ClassIsland 主程序版本、RemoteCI 插件版本、当前已加载插件清单和最近一次升级状态。设备离线时仍会显示服务端保存的最后一份版本快照，重新上线后自动覆盖。

- 修改时间表：在 WebUI 中填写时间表名称、起止时间和时间点类型，可新建或替换一张时间表，并可设为当前启用。
- 远程分发：上传或粘贴 ClassIsland 档案 JSON，按时间表、课表、科目选择分发范围。默认把选中的内容写入一个新档案并启用它，“导入档案名”留空时使用 JSON 中的档案名称；勾选“覆盖当前档案”才会写入设备当前档案，“替换档案中同 Id 的现有数据”只决定所选范围内的同 Id 数据是否先清空。
- 插件管理：支持批量安装、卸载、启用或禁用插件。安装会从 ClassIsland 官方插件市场解析依赖并下载 `.cipx` 包，重启后安装；卸载和启停通过宿主公开的插件状态接口标记，重启后生效。为避免失去远程控制，RemoteCI 会拒绝操作自身。
- 软件更新：支持批量刷新版本清单、升级插件和升级 ClassIsland 主程序，命令按在线插件连接逐台定向下发。
- 加入集控：上传 ClassIsland 的集控配置文件 `ManagementPreset.json`（或粘贴其内容），设备按文件中的服务器类型（Serverless manifest 模板或 ManagementServer 的 API + gRPC）加入内置集控；集控 ID 自动使用目标设备所属班级名，加入前会校验清单核心版本，写入宿主集控配置后自动重启。
- 插件管理策略：限制 RemoteCI 发起的远程插件安装或卸载，不影响在 ClassIsland 本地设置页操作。
- 远程终端：在设备上以当前登录用户执行一条命令并取回输出。每条命令通过 `cmd /d /c` 独立执行，命令之间不保留状态；命令最长 4000 字符，可选工作目录，超时 1-10 秒（默认 10 秒），超时的进程会被强制结束并返回已捕获的输出。标准输出与标准错误合并返回，上限 64K 字符，超出部分截断。命令正常结束即视为成功，退出代码显示在结果中，非零退出代码不算失败。
- 扩展插件：各班设备安装同一个支持 RemoteCI 的 ClassIsland 插件后，批量控制页会自动出现以该插件命名的分组，列出它注册的、已在扩展策略中启用的功能。点击功能卡片填写参数后选择目标，即可批量执行；未安装该插件的设备会在结果中显示“扩展功能不存在”。插件声明了设置页时，分组中还有“插件设置”卡片，进入扩展插件设置页统一修改各班设置。
- 文件分发：把一个不超过 10 MB 的文件发送到设备的桌面、下载或文档文件夹，不能指定其他路径。默认不覆盖同名文件而是自动追加序号，勾选“覆盖同名文件”才会替换；结果中显示文件在设备上的完整保存路径。

远程终端和文件分发位于“远程维护”区，在“批量控制”和班级“控制”页都可使用，执行结果按设备逐台显示在当前页面。

升级、插件管理、集控加入、策略下发、远程终端和文件分发都属于高风险维护操作，只允许系统管理员执行（班主任即使拥有“人员管理”权限也会被服务端和插件拒绝），并且需要在目标弹窗中再次勾选确认。命令下发成功只表示设备端已接受任务；下载、部署或重启的最终结果通过重新连接后的版本清单和升级状态展示。

## 手机端

Android 手机应用使用 Material 3 Expressive，承接 WebUI 与手表的课表、课堂控制、人员凭证和账号设置。

### Android 桌面小组件

Android 客户端提供三种桌面小组件，尺寸遵循小米澎湃 OS（HyperOS）小部件规范的 2×2、4×2、4×4：**当前时间状态**（2×2 与 4×2）、**今日课表**（4×2 与 4×4）和 **换课**（2×2）。当前时间状态显示今天页时间状态卡中的状态、课程、时间段、进度和下一节课，4×2 版本横向排布；在高密度桌面网格下 2×2 会收起次要行以免截断。今日课表至少显示下一节课和时间，组件越高显示的课程越多；未登录或课表未同步时显示提示。换课组件点击后直接打开手机端换课入口。同一功能的不同尺寸在小部件中心聚合为一个组件。小组件支持深色模式，并为读屏提供整块播报内容。

小组件读取手机最近一次有效的课堂状态与七日课表缓存，网络暂时不可用时仍显示最后一次同步内容；课堂状态或课表推送到达后会立即刷新，并以一分钟级系统闹钟补充更新当前进度。缓存按服务器、账号和当前班级隔离：切换账号或服务器、退出登录、登录失效时会清空小组件内容，切换班级时清空上一个班级的课堂与课表，不会显示上一个账号或班级的数据。老师账号的“当前时间状态”优先显示个人日程（个人日程暂时拉取失败时回退为当前班级状态）；班主任默认显示本班状态。

小组件的尺寸、布局、深色模式和独立 `:widgetProvider` 进程均按小米 Widget 规范实现，应用不依赖小米私有 SDK。在小米澎湃 OS 上，请在桌面双指捏合或负一屏“+”进入小部件中心，通过“搜索 → 安卓小部件”找到 RemoteCI 并添加；其他 Android 启动器按标准桌面小组件添加。小米小部件中心的独立展示与曝光刷新需要通过小米审核后才能开启（带小米标识但未通过审核的组件在两个入口都不会显示），在此之前小组件依靠应用推送与一分钟级定时刷新保持最新。登录页可以扫描 WebUI 概览中按需生成的“手机扫码登录”二维码：二维码携带服务器地址、登录 ID 和一次性票据，手机凭票据直接登录当前 WebUI 账号，无需再输入密码；票据 5 分钟内有效且只能使用一次，请不要在投屏或截图中展示。在“账号与设置 → 连接与服务器”页扫码同样会直接切换到二维码所属的服务器与账号。旧版只含服务器地址的二维码仍会作为服务器地址填入。

登录后可同步当前课堂与七日课表；有权限时可换课、发送通知/语音、控制主界面、音量和电源，并管理角色、账号、插件配对码、自动拉取周期和备份。控制命令的成功、失败和断线未发送状态会在当前页面显示。手机已保存会话会先直连局域网，连接成功后后台刷新云端管理 API 令牌，不阻塞首屏连接。底栏“管理”页只列出当前账号有权限的管理项（访客访问、角色配置、账号管理、插件配对码，均需“人员管理”权限）；一项都没有时底栏不显示“管理”页。账号管理支持从账号角色下拉列表创建用户，访客访问与自动进入访客页集中在“访客访问”子页面分别设置；插件配对码可选中或一键复制。修改密码与设备会话移到“账号与设置 → 密码与设备会话”，所有账号都可使用，设备列表会区分 Android 手机和手表。

“管理”页和“控制”页底部分别显示“更多管理操作请使用WebUI”“更多控制操作请使用WebUI”。点击蓝色的“WebUI”链接，手机会通过当前连接的服务器地址申请一张 1 分钟内有效、只能使用一次的网页登录票据，并用系统浏览器打开 WebUI，自动登录当前账号（替换浏览器里原有的 WebUI 登录），直接进入“人员权限”或“控制”页，并沿用手机上当前选中的班级。

上学期间手机端会发布可更新的“上课状态”持续通知，包含时间状态、这节课、剩余时间和下一节课（剩余时间由系统计时器倒数到本阶段结束时刻，超级岛右侧同样显示“距下课/上课”倒计时；正文第一行为本时段时间，第二行为“下一节：课程 时间”，上课时图标为日历、课间为勿扰月亮；课间超级岛显示“课间-下一节课名”，进入 ClassIsland 上课提醒设置的准备时长（室内/室外课分别生效，含科目/时间点附加设置）后切换为“即将上课-下一节课名”；上课期间“下一节”为当堂课结束后的第一节课）；放学或没有课程时自动撤销。老师账号从“我的日程”跨班级接口读取当前课与下一节课，学生账号使用当前班级的实时状态。通知同时携带小米 HyperOS 焦点通知、超级岛和息屏（AOD）字段；Android 16+ 还会请求 Live Update promoted ongoing。系统不支持时仍显示普通 Android 持续通知。小米 17 Pro、17 Pro Max、18 Pro、18 Pro Max 的原生 Smart Assistant 背屏卡片由 HyperOS 系统服务和设备白名单控制，正式上线需要按小米平台要求完成场景审核和设备白名单联调。

老师账号的课表页默认显示“我的日程”，按天列出各任教班级的科目、教师、节次与时间，可切换到“本班课表”；班主任账号的课表页默认显示“本班课表”，也可切换到“我的日程”。课表页的“拉取课表”和“账号与设置”里的“自动拉取课表”只对系统管理员和当前所选班级的班主任显示；其中“自动拉取课表”是对全部班级生效的全局设置，只向系统管理员显示；班主任能否拉取课表受[班主任权限](#班主任权限)控制，未获准时会立即提示“没有本班课表拉取权限”而不是一直等待；系统管理员可在“账号与设置 → 姓名”修改自己的用户名。

可访问多个班级的账号登录后会先选择进入的班级；之后点击首页左上角菜单进入“账号与设置”，在“当前班级”中切换。首页不再显示顶部班级切换行。

“账号与设置 → 外观”可以通过系统列表与单选控件独立选择浅色、深色或跟随系统，并在淡紫、经典紫、蓝、绿、橙、粉六套配色中切换；六套色值与 Wear OS 保持一致。首页底栏切换只替换正文，底栏本身不参与页面滑动动画。手机 WebSocket 使用 `client=mobile`，课表拉取来源为 `ScheduleSyncSource.Mobile = 6`，不会占用“在线手表”计数。

## API 接入

RemoteCI 的 REST API 复用 WebUI 与客户端同一组 `/api/*` 端点。管理员、班主任和老师默认拥有“API 访问”权限，学生默认没有；管理员可在“人员权限”中按角色默认权限或账号附加权限调整。

有权限的账号可在“个人账号 → API Key”创建和吊销自己的密钥，管理员也可在“人员权限 → 编辑账号”中代管。密钥明文只显示一次，服务端只保存摘要，权限始终按账号当前角色与附加权限实时计算；吊销密钥、禁用账号或移除“API 访问”权限后立即失效。

调用方式、端点清单、命令编号、错误码和 PowerShell 示例见[API 接口](../server/api.md)。

## 手表端操作

控制页中的操作由服务端检查账号权限后交给在线插件执行，并返回真实回执。插件离线、权限不足、课表已变化或等待超时时，操作会失败，不会静默排队。

- 首页：旋转表冠或表圈可在课程状态页与菜单页之间切换，一格翻一页；菜单页直接展示功能选项，无需滚动。下课和“即将上课”状态下，主课程按钮直接显示下一节课及其时间；时间按钮会根据时间段文字自动扩展，并限制在屏幕安全宽度内。
- 换课：先选择日期，再从课程按钮选择原节次和目标节次，或用指定科目替换；提交时携带课表修订号，防止覆盖别人刚完成的修改；可打开“永久换课”让修改写入源课表并持续到之后每周。
- 快速换课：主界面点击课程按钮可直接进入换课页；上课中预选当前课，下课或即将上课时预选按钮所显示的下一节课；在“暂无课程”但仍有下一节课时，下一节课科目会显示圆角描边，点击后同样把该课预选为原课。以上入口均无需先选日期，返回键直接回主页。
- 发送通知：向 ClassIsland 发送自定义通知，成功后广播给手表。

## 控制功能

手机和手表按**当前所选班级**的插件能力显示控制项：服务端为每个可访问班级分别下发该班主插件的能力，切换班级后立即按新班级刷新，不会因为其他班级的插件离线而隐藏本班控制项，也不会在本班插件离线时误显示可用。手机端扩展参数按类型显示开关、选项（使用插件提供的选项显示名称）、数字键盘和多行文本，并在发送前按服务端规则校验；手表的选项参数同样显示显示名称。

WebUI 与手表共用同一套命令、权限和插件真实回执：

- 发送通知：向 ClassIsland 发送自定义通知；WebUI 直接在控制页面填写标题和正文；标题是否附带发送人由系统管理员在“系统配置 → 通知人显示”统一设置。
- 清除提醒：清除 ClassIsland 当前提醒。
- 主界面：显示或隐藏 ClassIsland 主界面。
- 电源：关机、重启、睡眠或休眠；休眠入口只在插件报告可用时显示。
- 音量：拖动 WebUI 音量条后自动提交；静音状态下向高调节会在同一条命令中自动取消静音。页面以插件上报的真实状态刷新。
- 扩展：控制页按插件分组列出扩展名和 ID，右侧提供“执行”和“编辑”。管理员可逐项启用、向非管理员开放，并设置是否显示在自己的手表；获开放且具备独立“扩展功能”权限的普通账号即可执行，并可单独关闭自己手表上的入口，无需同时拥有通知或电源等其他权限。云端和局域网都会同步同一策略。

## 语音消息

语音消息的通知仅显示标题，不显示空白正文区域；普通通知的正文为空或只有空白字符时也采用相同表现。

在 WebUI 或手表的“控制 → 发送语音”中开始录音，停止后可试听、丢弃或发送，每条最长 60 秒。账号或自定义角色需要单独授予“发送语音”权限；“发送与清除通知”不会自动获得语音权限，管理员拥有全部权限。需同时更新服务端、手表和 ClassIsland 插件，旧端未声明语音能力时入口隐藏。

课表端收到后显示“来自xxx的语音消息”，xxx 使用账号显示名称。通知开启强调特效，关闭通知音效和文字朗读，录音自动播放；效果仍受 ClassIsland 全局提醒开关限制。屏幕下方的紧凑浮窗缓缓上滑出现，拖动标题可移动；顶部左侧显示发送人，右侧显示总时长，中间使用 ClassIsland 原生滑动条拖动播放位置。底部三个无底色的大号 ClassIsland 图标分开放置，分别用于暂停/继续、每次后退 5 秒和关闭，其中关闭图标为系统危险色，播完后可重新播放。浮窗使用 ClassIsland Fluent 浮层背景、描边、圆角、深浅色主题和宿主 UI 字体；点击浮窗外部也会关闭并停止播放。已有语音浮窗时，新消息返回忙碌提示，请先关闭已有浮窗再发送。

浏览器需通过 HTTPS 或 localhost 访问并允许麦克风权限，普通局域网 HTTP 地址无法录音。使用反向代理时，上传大小上限需至少 2 MiB，否则长录音可能出现 HTTP 413。手表首次使用会请求麦克风权限；切到后台或离开页面会停止采集。录音只保留在内存中，发送失败时可在当前页面重试；离开页面会丢弃草稿。服务器不保存语音文件，其他在线手表仅收到语音消息提示，不会自动播放这段录音。

语音不会绕过电脑的系统音量或静音设置。发送成功表示课表端已启动播放；若未收到回执，请先确认课表端是否已经播放，避免重复发送。

## 开发者连接设置

正常使用时，插件和手表都应保持云端中转与局域网能力开启，因此普通连接页面不提供关闭开关。插件普通“RemoteCI 设置”中的“显示开发者设置菜单”默认关闭；开启并重启 ClassIsland 后，“RemoteCI 开发者设置”会提供云端和局域网服务开关，以及按真实通知、播放和浮窗流程运行的“测试接收语音”。手表在“设置 → 开发者”提供“云服务器”和“局域网直连”两个高级开关，并提供“应用并重连”。关闭后只适合诊断连接问题：插件关闭云端后无法继续刷新账号权限镜像，关闭局域网服务后不再接受手表直连；手表关闭局域网后不会尝试插件直连，关闭云端后也不会在局域网失败时回退。

手表密码只由云端服务端验证，所以密码登录会临时启用一次云端认证，即使开发者此前关闭了后续云端连接。这样退出账号不会把设备锁在无法登录的状态；认证完成后的重连仍尊重开发者设置。

插件每次连接服务端都会上报当前监听端口和所有可用局域网 IP。服务端向在线手表转发并为新连接缓存最近结果；手表保存候选地址和端口，依次尝试直连并记住成功地址。普通“设置 → 连接”仍可手动修改 IP 与 1-65535 范围内的端口，用于指定网卡或诊断自动发现。

首次登录页提供“扫描局域网设备”。手表通过 UDP 48765 发现插件，选中后从插件读取云服务器地址并补齐局域网 IP/端口；用户确认云地址后，密码仍直接由云服务器验证。鉴权成功后优先切回局域网，成功时不建立重复的云端 WebSocket。反方向上，从云端首次登录仍会由服务端补齐插件的局域网地址，因此任意一种已知连接信息都可以补出另一种。

::: warning 操作前确认
换课、替换课程、电源与音量会改变教室电脑的真实状态。正式使用前应先在测试课表中确认行为。
:::

## 通知

插件可以把七类事件同步给手表，手表端可以逐类开关并触发系统通知和振动：上课、课间、放学、课表变更、自定义消息、ClassIsland 自动化“显示提醒”、第三方 ClassIsland 插件通知。

课程事件的正文由插件生成，直接写明具体内容：

- 上课：哪个班上什么课，例如“高一（1）班 数学课（08:00-08:45）”。
- 下课：下节课是什么，例如“高一（1）班 下节课：物理（09:00-09:45）”；当天没有后续课程时提示“今天没有后续课程了”。
- 课表已更新：列出科目发生变化的节次，例如“今天第 2 节 数学 换为 英语；第 3 节 英语 换为 数学”。一次超过 6 处变化时只列前 6 处并注明总数；只改了教师或课表名等、没有科目变化时显示“课表已更新”。

班级名优先使用服务端下发的插件归属班级，其次使用插件设置里的“班级备注”；两者都为空时正文省略班级名。

手机与手表的课程通知、换课通知和“上课状态”常驻通知默认都是高优先级，并开启横幅、声音和振动。“上课状态”常驻通知只在首次出现时提醒一次，之后的倒计时刷新保持安静。

自定义通知的标题与正文均可留空：标题留空时显示默认标题“RemoteCI 通知”，正文留空时保持为空，由 ClassIsland 只显示标题。通知由插件执行时添加“由用户名发送：”前缀（可由服务端全局设置关闭），发送者名称取账号的用户名（显示名），客户端无法覆盖。通知请求还可以分别控制提醒强调特效、提醒音效、语音朗读和“提醒时置顶主界面”；省略时均为关闭。发送自定义通知时还可设置**持续时间（秒）**、**重复次数**与**正文滚动显示**，WebUI 与手机端提供相同的选项。持续时间留空时按 ClassIsland 集控的默认值 5 秒处理，最长 3600 秒；重复次数留空时按 1 次处理，最多 10 次；标题最多 60 字，正文最多 500 字，超出范围的请求会被服务端和插件拒绝。WebUI 与手机端发送界面中正文滚动显示默认关闭：关闭时正文静态显示，每次显示“持续时间”秒，整条提醒依次显示“重复次数”次；开启后正文横向滚动“重复次数”遍，总显示时长为“持续时间 × 重复次数”，与 ClassIsland 官方集控服务器的“持续时间”“重复次数”语义一致。正文超过 30 字且未开启滚动时，WebUI 与手机端会提示建议开启滚动，以免静态正文显示不全。旧版插件不识别该开关，仍按滚动方式显示；未发送该开关的旧版客户端（如旧版手表）也保持原来的滚动显示。

## 更新

- 服务端：管理员在“系统配置 → 系统更新”选择正式版或 Beta 渠道；正式版排除预发布，Beta 同时包含正式版和预发布。强制更新可重新下载并覆盖同一版本，但不允许降级；Windows、Linux 与 Docker 会按各自安全流程替换实际程序集目录并自动重启。Development 环境由 Visual Studio 或 <code>dotnet build</code> 管理，WebUI 不提供覆盖更新入口。
- 手表：在“设置 → 更新”选择正式版或 Beta 渠道，设置会保存在本机。强制更新可重新下载并覆盖同一版本，但不能降级；必须先连接 WebUI，正式版只选择协议主版本相同的四段纯数字 Release，Beta 额外包含 `v3.x.x-beta.y`，V4 不进入自动更新候选。安装确认回调使用 Android PackageInstaller 的可变显式 PendingIntent。
- 插件：升级由 ClassIsland 插件市场统一管理；稳定版使用同一个四段纯数字 Release，固定资产名为 `RemoteCI.Plugin.cipx`，Release 正文包含与资产同名的 `CLASSISLAND_PKG_MD5` 标记；`v3.x.x-beta.y` 只用于三端测试，不进入市场。
- 飞牛 fnOS：从 GitHub Release 下载在线或对应架构离线 FPK，并由 fnOS 应用中心手动升级；WebUI 不提供下载按钮。

协议 V3 与软件版本独立。协议号为 3 的服务端、插件和手表可以连接；稳定更新只识别 `3.<数字>.<数字>.<数字>`，Beta 更新额外识别 `v3.<数字>.<数字>-beta.<数字>`，旧三段 `v3.x.x` 稳定标签不再作为新渠道候选。未上报能力的旧 V3 端按 V3 基础能力处理（该基线自 3.1.0 引入）。手表按“手表本地 ∩ 服务端 ∩ 当前主插件”隐藏不支持的功能，所以某块手表缺少能力不会影响 WebUI 使用服务端与插件共同支持的功能。管理员可在概览页查看每个连接的软件版本、能力来源、有效能力和缺失能力；英文能力标识后同时显示中文说明，例如 `schedule.read（读取课表）`。

## 外观主题

手表在“设置 → 外观”中可以切换整套 Material Design 3 配色方案，选择后立即生效并保存在本机，重启不会丢失。内置方案：

| 配色 | 说明 |
| --- | --- |
| 淡紫 | 默认方案，对齐现有 Figma 设计与 M3 淡紫容器色 |
| 经典紫 | M3 默认紫色（primary #6750A4）系列 |
| 蓝色 | M3 blue 官方色板 |
| 绿色 | M3 green 官方色板 |
| 橙色 | M3 orange 官方色板 |
| 粉色 | M3 pink 官方色板 |

配色切换只影响手表应用自身的界面（首页、课表、设置等），不会改变通知内容或协议行为。

手表界面会读取系统报告的屏幕形状：圆形设备保留圆形安全画布，矩形设备使用完整屏幕区域；两种形状都以屏幕短边作为组件缩放基准。

手表首页没有当前课程时，状态标题直接显示“暂无课程”，并隐藏无效的当前课程按钮；如果快照与已同步课表中存在可匹配的下一节课，则用圆角描边标出该科目，点击可进入换课页并将它选为原课。存在当前课程时，课程按钮会随课程名称长度伸缩，并与下方时间框统一采用两者中较长的宽度。
