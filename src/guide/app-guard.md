# 应用守护

在 WebUI 的“管理 › 应用守护”中，系统管理员可以为全校教室电脑统一开启应用守护，让 ClassIsland 保持运行：

- **退出自启**：ClassIsland 被正常退出后自动重新启动。可设置延时，例如“退出 40 分钟后自启”；设为 0 时立即启动（实际至少等 10 秒）。
- **意外退出时重启**：ClassIsland 崩溃或在任务管理器中被结束后，5 秒内重新启动。10 分钟内意外退出超过 3 次时，暂停自动重启 10 分钟。
- **禁止删除**：定时把 ClassIsland 备份到 C 盘。发现被删除后，自动恢复、重新启动，并用 ClassIsland 自带的对话框提示：

  > 当前ClassIsland由{组织名}统一管理，请勿自行删除，当前实例已由RemoteCI自动恢复。

组织名在“系统设置 › 常规 › 组织信息”中设置，留空时显示 RemoteCI。

::: tip 需要新版插件
应用守护由教室端插件部署并执行，需要升级到支持该功能的 RemoteCI 插件。“应用守护”页的设备列表会把旧版插件标为“插件版本过旧”。
:::

## 全局策略与单台设备

- **全局策略**：对所有教室电脑生效。保存后，在线设备立即收到；离线设备在下次连接服务端时收到。
- **单独设置**：在设备列表中点“单独设置”，这台设备就改用自己的完整策略；点“恢复沿用全局”即可撤销。
- **断网时**：插件会记住最近收到的策略，教室电脑断网启动时照样生效。

## 它是怎么工作的

ClassIsland 退出或被删除时，插件也随之停止，所以实际的守护工作由插件部署的独立小程序 `RemoteCI.Guard.exe` 完成：

- **位置与权限**：程序和备份都放在教室电脑的 `%LOCALAPPDATA%\RemoteCI\Guard`（C 盘当前用户目录）。程序随登录 Windows 自动运行，不需要管理员权限。
- **不依赖 ClassIsland**：它使用 Windows 自带的 .NET Framework，ClassIsland 连同它自带的运行时一起被删除后照样能工作。
- **如何区分退出方式**：插件会在 ClassIsland 正常退出前留下标记。有标记时按“退出自启”的延时处理；没有标记就视为意外退出。
- **远程升级时**：通过 RemoteCI 远程升级 ClassIsland 的 15 分钟内，守护程序不做干预。
- **注销与关机时**：守护程序不会启动 ClassIsland。
- **自我修复与自动更新**：ClassIsland 运行时，插件每分钟检查一次守护程序：被结束就重新拉起，被删除就重新部署，与插件自带的版本不一致就替换为新版本。因此“应用守护”页提示“守护版本过旧”时，只要课表插件上线，一分钟内即会更新；也可以点设备行的“更新守护”立即强制覆盖升级，失败原因会直接显示在页面上。设备行会显示守护版本，守护已与插件版本一致时不显示该按钮。如果提示要先升级课表插件，说明守护的新版本还没有随插件装到这台电脑上。远程关闭或卸载守护后，插件不会再拉起它。

### 备份与恢复

- **备份范围**：ClassIsland 安装目录（含文件夹版的 `data`、插件与配置），以及安装目录之外的 ClassIsland 数据目录。日志、缓存和临时文件不备份。
- **何时备份**：ClassIsland 运行期间按设定间隔（默认 24 小时）增量备份；ClassIsland 版本变化后立即备份一次。
- **自动跳过**：需要备份的内容超过 2 GB，或安装目录突然少了大量文件（疑似正在被删除）时，跳过本次备份并上报“备份失败”。
- **恢复方式**：只补回缺失的文件，不覆盖仍存在的文件。恢复后重新启动 ClassIsland，并在新打开的 ClassIsland 中弹出提示。

### 守护事件

“应用守护”页底部列出最近的守护事件，保留 90 天：

- 已自动恢复
- 恢复失败
- 意外退出后重启
- 退出后自启
- 频繁崩溃暂停重启
- 备份完成
- 备份失败

其中“已自动恢复”和“恢复失败”还会以个人通知的形式发给全部系统管理员（WebUI 铃铛、浏览器通知、手机、手表与 AstrBot）。

## 关闭应用守护

关闭全局或单台设备的守护后，插件会：

- 结束守护程序；
- 删除登录自启项；
- 删除 `%LOCALAPPDATA%\RemoteCI\Guard`，包括其中的备份。

## 注意事项

- 应用守护用来防止误操作和随手关闭、删除，不是防篡改机制。熟悉系统或有管理员权限的人仍然可以同时删除守护程序与备份。
- 通过 Microsoft Store（MSIX）安装的 ClassIsland 不支持“禁止删除”，其余两项照常生效。
- 只守护当前登录 Windows 账号的 ClassIsland。
- 接口说明见 [API 接入 · 应用守护](../server/api.md#应用守护)。
