# 调休

RemoteCI 服务端会自动获取国务院公布的法定节假日与调休安排（数据来自开源项目 [holiday-cn](https://github.com/NateScarlet/holiday-cn)），并下发到每台教室电脑：

- **放假日**：ClassIsland 自动关闭课表，不显示课程、不提醒上下课；第二天上学时自动恢复。如果放假当天有老师手动重新打开课表，插件当天不会再关掉；插件也不会去打开别人手动关闭的课表。
- **调休上学日**（原本是周末但要上学）：自动为这一天建立一份临时课表，内容是某个工作日的课。如果这一天已经有人手动安排了课表，插件不会覆盖它。

WebUI、手机和手表的七日课表中，放假日显示为“放假 · 假期名”，调休上学日显示为“调休 · 假期名”。放假日不能换课。

## 补哪天的课

服务端会自动推算：同一个假期里，调休上学日按时间顺序依次对应这个假期最后几个放掉的工作日。以 2026 年国庆为例，9 月 20 日（周日）上周二的课，10 月 10 日（周六）上周三的课。课表取自调休上学日所在那一周对应工作日的课表，多周轮换按那一周计算。临时课表在调休上学日前 7 天内建立。

学校的实际安排不同时，系统管理员可以在 WebUI 左侧导航「调休」页，把每个调休上学日改成上周一至周五的课，或者设为「不补课」。无法自动推算的日期会标红，需要手动指定后才会开课。修改后会立即下发到在线的教室电脑，已经建立的临时课表会按新安排重建或撤销。

## 设置

| 设置 | 说明 |
| --- | --- |
| 启用调休自动适配 | 默认开启。关闭后，插件会撤掉之前建立的、尚未到期的临时课表，并恢复它自己关掉的课表开关。 |
| 数据源地址 | 留空时依次使用 jsDelivr 和 GitHub 上的 holiday-cn。也可以填写自己维护的同格式文件地址，必须是包含 `{year}` 的 https 地址；填写后只使用这个地址。 |

服务端启动时拉取一次今年和明年的数据，之后每 12 小时拉取一次，也可以点击「立即刷新」。明年的数据通常在当年 11 月后发布，此前的“尚未发布”不算错误。数据源暂时无法访问时继续使用上次成功获取的数据；教室电脑断网时继续按最后收到的安排生效。

## 通过 API 与机器人使用

- REST API：`GET /api/holidays` 查询，`/api/admin/holidays/...` 修改，详见 [API 文档](../server/api.md#调休)。
- AstrBot 插件：`/rci 调休` 查看近期假期与补课安排，管理员可用 `/rci 调休 2026-10-10 周三`（或 `不补课`、`自动`）修改；也可以直接用自然语言询问。

## 版本要求

服务端和教室端插件都需要升级到包含此功能的版本。旧版插件不会收到调休安排，课表保持原样；新版插件连接旧版服务端时也不会做任何调整。
